# 📰 FattiDiretti

Full-stack news and digital publishing platform developed for **FattiDiretti**, an independent online news project.

The platform was designed to provide a modern publishing experience for readers while giving administrators the tools needed to create, manage and publish editorial content.

## 🌐 About the Project

FattiDiretti is a real-world digital publishing platform built to manage news articles, categories, multimedia content and user interactions.

The project combines a public-facing news website with an administrative environment for editorial content management.

The platform has been continuously improved and modernized based on real publishing requirements.

## 🏗 Architecture

The application follows a component-based React architecture with separate responsibilities for:

- Public news pages
- Article rendering
- Categories
- Multimedia content
- Authentication
- User profiles
- Administrative tools
- Firebase services

The architecture was designed to support continuous development and new editorial functionality.
